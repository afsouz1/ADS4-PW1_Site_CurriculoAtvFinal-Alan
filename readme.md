# Meu Currículo - HTML, CSS e JavaScript

Este repositório contém o desenvolvimento do meu currículo digital utilizando HTML, CSS e JavaScript.

## Requisitos Técnicos

- **HTML5 e CSS** responsivo com foco em **Mobile First**.
- Duas versões de tema: **claro e escuro**.
- Persistência do tema no **Local Storage** utilizando **JavaScript**.
- Implementação de **animação** personalizada.
- O site pode ser **single page** (com âncoras e menu de navegação) ou **multi-page**.
- Caso o menu seja fixo no início da página, implementar um **botão voltar**.
- Uso de **imagens** para tornar a experiência mais rica e visualmente atraente.

## Requisitos de Negócio

O site contém as seguintes seções:

1. **Introdução** - Breve apresentação pessoal para novos visitantes.
2. **Habilidades** - Exposição de **Hard Skills** e **Soft Skills**.
3. **Experiência Profissional** - Listagem de trabalhos anteriores e responsabilidades desempenhadas.
4. **Projetos Desenvolvidos** - Exibição de projetos pessoais e profissionais, com imagens e descrições.
5. **Cursos e Eventos** - Cursos e eventos relevantes que contribuíram para minha formação.
6. **Contato** - Informações de contato, incluindo redes sociais e e-mail profissional.

## Diretrizes para um Currículo Digital Atraente

- **Design Atraente**: Escolha um layout que reflita minha personalidade.
- **Introdução Impactante**: Criar uma primeira impressão marcante.
- **Destaque de Habilidades**: Uso de gráficos ou ícones para ilustrar competências.
- **Exibição de Projetos**: Capturas de tela e links para repositórios no GitHub.
- **Depoimentos e Recomendações**: Feedbacks de colegas ou clientes.
- **Experiência Profissional**: Enfatizar realizações e resultados obtidos.
- **Toque Pessoal**: Adicionar informações sobre hobbies e interesses.
- **Mídia Visual**: Uso de imagens, ícones e possivelmente vídeos.
- **Responsividade**: Garantia de compatibilidade com dispositivos móveis.
- **Fácil Contato**: Informações de contato acessíveis para networking.

## Como Executar o Projeto

1. Clone o repositório:
   ```sh
   git clone https://github.com/seu-usuario/meu-curriculo.git
   ```
2. Acesse a pasta do projeto:
   ```sh
   cd meu-curriculo
   ```
3. Abra o arquivo `index.html` no navegador.

## Tecnologias Utilizadas

- **HTML5**
- **CSS3** (Flexbox, Grid e animações)
- **JavaScript** (Local Storage, manipulação do DOM, animações)
